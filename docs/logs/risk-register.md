# Risk Register (index)

One row per risk, kept current through every phase. The detail of each risk lives in its phase's `risk-register-entry` collection artifact (`RSK-NNN.md`), where each risk is a `## Risk R-N` section. This index holds the live status: producers add a row when they raise a risk (using ID format `RSK-NNN R-N`) and update Likelihood, Impact, Mitigation, Status, and Last reviewed as work changes it; at every phase gate each Open or Mitigating risk is reviewed (`.ai/standards/phase-loop.md`, Step 8). Status: Open | Mitigating | Closed | Accepted. Accepted needs a named human decision in `docs/logs/decision-log.md` (DEC-NNN in Mitigation).
