### Summary
Bootstraps the Django 5.2 LTS project scaffold (`src/aplx_ams_django/`) with a health check endpoint at `GET /api/health/` returning HTTP 200 and `{"status": "ok"}`, a Docker Compose environment (app + PostgreSQL 18 services), and a GitHub Actions CI pipeline wiring all 7 gate jobs (methodology, lint, typecheck, sast, deps, secrets, test, migrate, build). Two version constraints were tightened from the plan to remediate CVEs found by the mandatory pip-audit gate: Django was patched from the initial 5.2.0 release to 5.2.18 (71 CVEs), and pytest was moved to the 9.x line to fix PYSEC-2026-1845 (both changes recorded as DEC-053 and DEC-054 by the tech lead).

### Known Gaps

### Deviations From Plan
- **DEC-053** (2026-10-17, Mohanasunder): Django version constraint tightened from `==5.2` (plan) to `>=5.2.18,<5.3` in `requirements.txt`. Reason: Django 5.2.0 has 71 known CVEs (PYSEC-2025-37, PYSEC-2026-3717, PYSEC-2026-4035); pip-audit is a non-overridable CI gate; 5.2.18 is the latest patch within the approved LTS line with no API changes.
- **DEC-054** (2026-10-17, Mohanasunder): pytest version constraint expanded from `>=8,<9` (plan) to `>=9.0.3,<10` in `requirements.txt`. Reason: pytest 8.x has PYSEC-2026-1845; the fix is in pytest 9.0.3+; pytest is a dev/CI-only tool not deployed to production; expanding the constraint resolves the gate without changing the running system.

### Risk Tier And Review Depth
Tier: Critical — Deep review required.

This feature is the CI infrastructure and repository scaffold; every subsequent feature depends on it. A broken gate or wrong directory layout would block the entire build phase. Per `.ai/standards/review-and-approval.md` § Approval tiers, Critical features require both the tech lead and the release manager as approvers, with Deep review depth.

Deep review means: read every changed line of logic; review security against the threat model and permission matrix (auth, validation, secrets, data exposure); run the feature locally including failure paths; check migrations and rollback; read every test for behavior.
